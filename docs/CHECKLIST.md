# Чек-лист приёмки (прогонять перед каждым релизом)

## Установка
- [ ] Свежая установка открывается без ошибок
- [ ] Новый APK ставится ПОВЕРХ без удаления
- [ ] Данные сохранились после обновления

## Календарь
- [ ] Месяц открывается, сегодня выделено
- [ ] Долгое нажатие на день → форма с датой
- [ ] Нажатие на день → список событий
- [ ] Пересечение времён → предупреждение
- [ ] «Весь день» → полоса в ячейке
- [ ] Будни со школьным расписанием → зелёные метки
- [ ] 📤 «Поделиться днём» отправляет текст

## Работа
- [ ] Услуга и клиент добавляются (у клиента — источник)
- [ ] Запись клиента через свободные слоты
- [ ] «Статус →» переключает 4 статуса
- [ ] «Завершено» попадает в итог месяца
- [ ] История клиента и кнопка звонка работают

## Семья
- [ ] Событие с участниками, в карточке видно «Идут: …»
- [ ] Покупки: добавить / отметить / очистить купленные
- [ ] Член семьи добавляется с ролью

## Школа
- [ ] Расписание ребёнка создаётся и правится

## Заметки
- [ ] Добавить / Готово / Изменить / Удалить

## Настройки и данные
- [ ] Тёмная тема переключает сразу
- [ ] Первый день недели меняет сетку
- [ ] Скрыть вкладку → исчезает; вернуть → появляется
- [ ] Экспорт JSON → Импорт восстанавливает данные
- [ ] Виджет «Сегодня» ставится на стол и показывает события

## Напоминания
- [ ] Напоминание приходит в заданное время
- [ ] После перезагрузки телефона напоминания живут
