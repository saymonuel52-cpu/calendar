# Семейный ежедневник

Офлайн-планировщик для семьи + CRM для мастера (шугаринг, LPG-массаж). Android 8.0+.
Все данные хранятся только на телефоне (Room). Интернет нужен только для сборки на GitHub.

## Возможности (v1)

- **Календарь**: месяц, блок «Сегодня», цвета категорий, пересечения с предупреждением,
  события «весь день», зелёные блоки «ребёнок в школе».
- **Работа**: запись клиентов через свободные слоты (рабочие часы), клиенты с источниками
  (Telegram/сарафан/…), прайс услуг, статусы записей, итог месяца «визиты · ₽», история клиента, звонок.
- **Семья**: события с участниками («кто идёт»), список покупок, члены семьи с ролями
  (родитель/ребёнок/помощник/питомец), здоровье (прививки, врачи).
- **Школа**: недельное расписание «ребёнок в школе» по каждому ребёнку.
- **Заметки**: блокнот с напоминаниями, «готово», редактирование.
- **Напоминания**: до 3 на событие, восстановление после перезагрузки.
- **Настройки**: тёмная тема, первый день недели, скрытие вкладок.
- **Данные**: экспорт/импорт JSON, «Поделиться днём», виджет «Сегодня».
- **Обновления поверх** без удаления и потери данных (стабильная подпись).

## Получить APK

1. Любой `git push` в main запускает сборку в GitHub Actions.
2. Actions → последний зелёный запуск → Artifacts → `app-debug` → установить на телефон.
3. Обновления ставятся поверх старого приложения.

## Разработка

- Код пишется с телефона (Termux), сборка — в облаке GitHub.
- Быстрая команда: `gp "сообщение"` = add + commit + push.
- При краше приложение показывает текст ошибки («чёрный ящик») — его можно скопировать и прислать разработчику.

## Безопасность

- Резервные копии: Настройки → Экспорт JSON.
- Ключ подписи `ci/release.keystore` генерируется CI автоматически (пароль `family123`).
  Пока репозиторий приватный — допустимо. Перед публикацией APK в магазин — перенести ключ в GitHub Secrets.

## Дорожная карта

- **v1** — готово (этот релиз).
- **v2** — финансы, профили настроек, Google Календарь, облачный бэкап, рабочие задачи.
- **v3** — синхронизация с электронными дневниками, сканер документов, голосовой ввод, погода.
